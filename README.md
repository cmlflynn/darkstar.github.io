# Milky_Way_Halo_Density_Laws

A webpage of models of the stellar halo in the Milky Way. 

Each model comes from a published paper of "tracer" stars in the halo.

The analytical model has been extracted from the paper using Gemini/cli, and implemented as a python code. 

A plot of each model is shown, and the values of the physical parameters, such as power-law indices, dentral densities, break radii, scale radii etc are shown.
