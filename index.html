Models of the Milky Way stellar halo

A compendium of stellar density profiles and analysis

This is a project in progress. The project is to understand how well AI tools can process papers on a topic in astronomy (the number density of stars in the Milky Way halo as a function of Galactocentric radius), produce summaries of the work, extract formulae of fitting models, work out what the best fitting parameters are, write code to plot the models, and estimate a new quantity (the integrated luminosity of the halo).
